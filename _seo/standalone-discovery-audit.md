## 第1回(2026-09-30、単発実況PoC #1 の直後)

### 結論

- 判定: **B**(候補抽出には使えるが、本番投入前の人間確認が必須。判定ロジックの改善が先)
- HIGH(監査ルール)Precision: 9/9 = 100%。ただし n=9 と少なく、HIGH 判定はスクリプトに未実装(監査側で付けた分類)

### 推奨運用

- **半自動(B)**: HIGH 候補を生成 → 人間が確認 → 承認分だけ STANDALONE_PLAYS に追加 → validate-data.ps1
- 完全自動は不可。理由は3点:
  - HIGH ルールがスクリプトに未実装
  - 説明欄の誤一致や最長一致の誤りが実際に起きている
  - 登録可能かどうか(VTuber×game の再生リスト優先)を discover 側で判定していない
- 手動のみは効率が悪い。候補の出る場所としては十分役に立つ(正解25本)

### 判定ロジックの改善案(次工程)

1. 信頼度(HIGH/MEDIUM/LOW)をスクリプトに実装する。【】の中身と name/alias の完全一致だけを HIGH にする
2. ゲーム判定はタイトルを優先する。説明欄は「配信タイトル:○○」の行だけ参考にし、それ以外の説明欄一致は LOW に落とす
3. 英数字のゲーム名は単語境界つきで照合する(UNO の誤一致を防ぐ)
4. 候補の段階で除外する:
   - STANDALONE_PLAYS に登録済みの video ID
   - 同じVTuber×ゲームの再生リストが登録済みのもの
   - #1 / #2 などの連番付き
   - チャンネル側に専用PLがあるもの(再生リスト方式へ回す)
5. 差分取得: アップロードの既知 video ID と、登録PLの video ID キャッシュ

## 判定ロジック改善 #1(2026-09-30)

### 結論

- 判定: **A**(HIGH の Precision は 25/25 = 100%。ただし件数が少なく、統計的な下限は 95% に届かないため S ではなく A とする)
- 第2回 PoC(本番候補は最大5件、人が確認してから登録)に進んでよい
- STANDALONE_PLAYS は 宙科そぴあ × 夜勤事件 の1件のまま。GAMES / aliases は変更していない

### 変更したファイル

- `standalone-matching.ps1`(新規): 判定ロジックの本体。HIGH / MEDIUM / LOW の条件はファイル先頭に書いてある
- `discover-standalone.ps1`: 旧来の「タイトル+説明欄の全文で最長一致」をやめて、上のライブラリを使う形に変えた
  - STANDALONE_PLAYS 登録済みの動画を除外するようにした
  - 候補に confidence / matchType / reasons / otherGames を出すようにした
  - YouTube API の取得部分は変えていない
- `test-standalone-matching.ps1`(新規): 回帰テスト 47件。実際の GAMES と STREAMERS を読み込んで使う

### HIGH の条件(すべて満たすときだけ)

1. タイトルの【】または [] の中身が、表記揺れを除けばゲームの name / nameJa / alias と完全に一致する
2. その名前を持つゲームが1つだけ(ダクソ・FF・ドラクエ など、複数のゲームで共有される alias は除く)
3. タイトルの中で、ほかのゲームが独立に一致していない
4. 非ゲーム語を含まない(雑談・歌枠・歌ってみた・cover・MV・切り抜き・告知・新衣装・凸待ち など)
5. 連番がない(#2 / Part2 / 第2回 / ep2 / その2 など。続き物は再生リスト方式で拾う)
6. 同じVTuber×ゲームの再生リストがサイトに登録されていない
7. チャンネル側に、そのゲーム名を含む再生リストがない

補足:

- 登録済み再生リストの動画と STANDALONE_PLAYS の動画は、判定の前に候補から外す
- 条件を1つでも満たさない場合、ゲームが特定できていれば MEDIUM にする
- 非ゲーム語を含むもの、説明欄だけで一致したもの(「配信タイトル:」の行は除く)は LOW にする

### 誤判定への対策

- **短い英数字のゲーム名(5文字以下: Rust / PEAK / UNO / APEX など)**
  - 前後が英数字・漢字のときは一致させない(単語境界)。trust や frustration が Rust に、Siokazunoko が UNO に一致しない
  - 【】の外で一致した場合は MEDIUM
  - 説明欄では照合しない
- **部分一致**
  - 前後の文字が漢字・英数字なら、境界が弱いとみなして一致させない
  - 一致した箇所が別ゲームの長い名前の中に収まる場合は、長い方のゲームだけを残す(DARK SOULS と DARK SOULS III など)
  - 一致した箇所が登録済みVTuberの名前の中にある場合は無視する(「大神ミオ」の中の「大神」など)
  - 【】の中身と名前の一部だけが一致した場合(【Coffee Talk Tokyo】と Coffee Talk など)は MEDIUM
- **表記揺れ**: 以下を揃えてから比べる
  - NFKC 正規化・大文字小文字・カタカナとひらがな・空白
  - 記号(・ : - 〜 ! ? . など)
  - ™ ®
  - ローマ数字 II〜IX を算用数字に(X は除く)
  - これで R.E.P.O. と REPO、DARK SOULS III と 3 と Ⅲ が同じになる
- **alias**
  - 複数のゲームで共有されている alias は HIGH にしない
  - 正規化したあとの長さが2文字未満の alias は使わない
- **複数のゲームに一致**: 独立して一致したゲームが2つ以上あれば、HIGH にしない

#### スト6 実況 一覧(A)

- 修正日: 2026-09-26
- 修正内容: ゲーム詳細「このゲームを実況しているVTuber」を、10組表示+残りは「もっと見る」クリック時に JS で生成、から、
  10組表示+残り全員を `<details>` 内に通常リンクとして最初から出す方式へ変更(ストリートファイター6 は 54組中 44組が対象)。
  title / description / canonical は変更なし。「スト6」の別名追加は短い略称の誤マッチ防止のため行わない。
- 理由: 「一覧」を求める検索に対し、title は「…を実況しているVTuber一覧」なのに、ページ上のVTuber一覧は10組しか無く、残りはクリックしないと存在しなかった。
- 見るべき指標: このクエリと「ゲーム名 実況 一覧 / VTuber」系クエリの CTR・掲載順位、ゲーム詳細→VTuber詳細の遷移。
